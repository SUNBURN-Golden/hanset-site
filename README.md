# hanset-site

HANSET(한셋) — Korean wellness / functional-fitness magazine + "Drop-in & Sauna Finder" directory. Static site generated by a stdlib-Python builder.

- Production: https://hanset.soulbound.co.kr (Cloudflare Pages project `hanset`, branch `main`)
- Latest known production deployment: `5c924e18` (2026-10-19 KST, archive illustrations release)
- Open PRs: none. Default branch: `main`. **Read [AGENTS.md](AGENTS.md) first** (lock rules).

## Layout
[Data foundation design, schema and migration](docs/data/README.md).
```
boxes.csv saunas.csv events.csv   source-of-truth data (price, last_verified, source URL, confidence). Venue contact columns are blanked in this repo.
site/build_site.py                builder (reads ../*.csv + site/content/*.json, writes site/dist)
site/content/venues.json events.json   Korean copy for the ONLY entries cleared to publish
site/content/pages/*.html         about / faq / guide / privacy / corrections fragments
site/content/articles/            magazine articles (markdown)
site/static/{css,js,img,fonts,root}   assets; root/* is copied to the dist root (Search Console verification file)
illustrations/                    hand-drawn style SVG/PNG generators (make_all.py, make_archive.py, make_bird.py) + outputs
articles/                         article research/drafts (no Gemini conversation links)
```

## Build / run
```
cd site
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # fonttools + brotli (font subsetting only)
.venv/bin/python build_site.py --release                               # REQUIRED for anything deployable -> site/dist
python3 -m http.server 8765 --directory dist --bind 127.0.0.1          # http://127.0.0.1:8765/
```
- The preview build (no `--release`) adds `noindex` — local look only, never deploy.
- With FontTools and a Brotli backend, the builder serves self-hosted Pretendard for body text. If either dependency is unavailable, body text uses the system font stack. The bundled Excalifont and Gaegu display fonts are available in both cases.
- Illustrations: `cd illustrations && python3 make_all.py && ./render_png.sh` (needs Chrome headless for PNG; fonts in `_fonts/`, SIL OFL). Copy updated SVGs into `site/static/img/{guide,archive}/`.

### Release build verification

From the repository root, use the site build environment created above for the
full build and separate temporary directories for each release. The FontTools-only
environment exercises a missing WOFF2 encoder backend.

```bash
verify_dir=$(mktemp -d)
site/.venv/bin/python site/build_site.py --release --out "$verify_dir/full"
python3 -E -S site/build_site.py --release --out "$verify_dir/stdlib"
python3 -m venv "$verify_dir/fonttools-only"
"$verify_dir/fonttools-only/bin/python" -m pip install 'fonttools>=4.50'
"$verify_dir/fonttools-only/bin/python" -c 'from importlib.util import find_spec; import fontTools; assert find_spec("brotli") is None and find_spec("brotlicffi") is None'
"$verify_dir/fonttools-only/bin/python" site/build_site.py --release --out "$verify_dir/no-brotli"
```

| Build environment | Body font output |
| --- | --- |
| FontTools and Brotli | Pretendard Regular and Bold WOFF2 subsets and license, CSS weights 400 and 700, and a Regular preload |
| Stdlib only | System font stack |
| FontTools without a Brotli backend | System font stack |

Require a successful exit, the `built … pages` summary and `leak check OK`
from each build. Excalifont and Gaegu must resolve in all three builds, including
the Excalifont preload. Each fallback build should warn once and omit Pretendard
files, preloads, and CSS font URLs. Resolve every HTML font preload and CSS font
URL relative to its document or stylesheet and check that it points to a nonempty
same-origin WOFF2 file. Check that each stylesheet's `?v=` matches the first eight
hex digits of the MD5 of its emitted bytes and that the full and fallback CSS
hashes differ.

Serve the full and fallback outputs locally. Open Home, Finder, a venue detail,
and Archive at mobile and desktop widths. Confirm that text is readable, fonts
load locally without failures, and internal links resolve.

## Deploy
Only the HANSET operations bot deploys, through its external release entry point on the operations box: `python build_site.py --release` plus Pages Functions bundling for Cloudflare Pages project `hanset` (owner-authorized 2026-10-19, see [AGENTS.md](AGENTS.md)). No deploy script or CI deploy step lives in this repo. PRs must be merge-ready: release build clean, `leak check OK`, no secrets. Frontend workers have no tokens — use the local build, test and loopback preview commands above; never deploy from a worker.

## Independent local collector

[`crawler/`](crawler/README.md) is a Linux local worker with automatic discovery,
approved browser extraction, privacy filtering, evidence review and five-stage
reporting. [`tools/chrome-clipper/`](tools/chrome-clipper/README.md) is its Manifest
V3 manual intake extension. Collector state lives outside the repository; the
legacy queue can be reported read-only. Neither system writes site content or
publishes. Browser dependencies and mandatory integration checks are separate
from the static site's build requirements.

## Suggested priority screens for frontend work
1. Home `/` (magazine home; illustration section at the bottom, mobile compact list)
2. Finder `/finder/` (filters, URL state, big-spa category filter)
3. Venue detail `/finder/<slug>/` (확인일 + 출처 block, safety line)
4. `/archive/` (hand-drawn archive gallery, tap-to-enlarge)

## Data flow (for context)
CSV (last_verified, source, confidence) → `venues.json`/`events.json` copy → release build → deploy by operations bot. The builder publishes a box only if confidence is verified/partial, a sauna only if read on an official page, an event only if organizer/official verified.

## Excluded from this repo (kept on the operations box)
Deploy pipeline and tokens, Cloudflare IDs, account credentials, mail/inbox text, venue contact details, Instagram/YouTube/video production assets (`instagram/`, `video/`, `youtube/`, `render/`), raw captures (`raw/`, `out/`), previews, backups (`*.bak*`, `_prev*`), `dist/`, `.venv/`, HANDOVER.md/PLAN.md/outreach drafts (contain secret paths, owner and venue contact info).
